# To-Do App

A simple and responsive task management app built with **HTML, CSS, and JavaScript**. It lets users create, manage, edit, and track tasks while keeping their data saved in the browser.

## Features

* Add new tasks
* Mark tasks as completed
* Undo completed tasks
* Edit existing tasks
* Delete tasks
* Track pending, completed, and total tasks
* Persist tasks using LocalStorage
* Responsive design for different screen sizes

## Built With

* **HTML5** — Structure and content
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic and interactivity
* **LocalStorage** — Saving tasks in the browser

## How It Works

1. Enter a task in the input field.
2. Click **Add** to create the task.
3. Mark a task as completed when you finish it.
4. Edit or delete tasks whenever needed.
5. Your tasks remain saved in the browser using LocalStorage.
